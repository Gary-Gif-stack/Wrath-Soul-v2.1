# Wrath Soul 2.0 (Fabric 1.21.1)

/give @s wrathsoul:wrath_soul

Keys (rebind under Controls > Wrath Soul):
  R Rage    G Adrenaline    Z Swift/Heavy mode    V cast awakening ability    B select next ability

Progression (stored on the sword):
  I   Stirring   - slay 50 hostile mobs    -> Soul Dash
  II  Roused     - slay 200 hostile mobs   -> Wrath Nova
  III Ascendant  - defeat Elder Guardian + Wither -> Spirit Warrior
  IV  Awakened   - defeat Warden + Ender Dragon   -> Soul Ascension, becomes the Awakened Wrath Soul

All numbers: src/main/java/com/wrathsoul/Balance.java
